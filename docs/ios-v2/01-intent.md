- 상태: 2026-10-29 결정 사항 D1–D5를 모두 기본값으로 확정했다.
- 다음 문서: [02-spec.md](./02-spec.md) → [03-plan.md](./03-plan.md)

## 한 줄 요약

내가 기록한 책·영화·시리즈·게임·공부의 표지가 화면 뒤를 넷플릭스 카탈로그처럼 채우고, 그 위의 Liquid Glass가 표지를 실제로 굴절시키는 iOS 네이티브 기록 앱. 아이폰 듀오의 접은 화면과 펼친 화면에서 하나의 경험으로 이어진다.

## 배경

### v1에서 한 일 (2026-07, `ios/` 커밋 20개)
- SwiftUI 네이티브 앱으로 웹 기능을 거의 전부 이식했다. 대시보드, 기록 허브와 카테고리별 상세, 세션 단위 타임라인, 작성 시트 5종, 설정, 홈 화면 위젯, Icon Composer 아이콘.
- 데이터 계층: SwiftData 로컬 우선 저장소(`PrismStore`, `StoredLog`)와 FastAPI(`https://prism.lawdigest.kr`) 동기화. 오프라인 쓰기, 엔티티 지연 생성, 페이로드 원형 보존까지 갖췄고 웹 패리티 테스트로 검증했다.
- 디자인 시스템: `PrismGlass`(콘텐츠 층 글래스 카드 + `GlassEffectContainer` 묶음 규칙), `SpectrumBloomBackground`(카테고리 색 그라디언트 세 개가 천천히 흐르는 배경).

### 남은 문제
- 글래스 뒤 배경이 어두운 단색(#1A1816)과 부드러운 그라디언트뿐이라 굴절시킬 경계와 형태가 없다. Liquid Glass를 넣어도 회색 반투명 판처럼 보이고 효과가 거의 드러나지 않았다.
- 레이아웃이 하단 탭바를 전제로 한 고정 여백(작성 버튼 `bottom 78`, 스크롤 `bottom 130`)에 기대고 있다.

### 아이폰 듀오
- 2026-10-23 출시, iOS 27.1. 바깥 화면 5.4"(compact width), 안쪽 화면 7.6"(정사각형에 가까움, regular width). 세로축으로 접히고 책 자세·테이블탑 자세를 지원한다.
- iOS 27.1 SDK로 빌드하면 두 화면 모두 edge-to-edge로 표시되고, 바깥 화면 등에서는 탭바·툴바가 세로로 바뀌어 옆 가장자리로 간다. 26 SDK로 빌드한 앱은 안쪽 화면 가운데에 작게 표시된다.

## 목표

| # | 목표 | 왜 |
|---|---|---|
| G1 | **굴절이 보이는 글래스** — 배경을 내 라이브러리의 표지 벽(Library Wall)으로 바꾼다 | v1에서 글래스가 티 나지 않던 원인을 정면으로 해결한다 |

| G3 | **아이폰 듀오 네이티브** — 접힘·펼침·책·테이블탑 자세에서 같은 계층 구조, 접고 펼쳐도 상태 유지 | 출시 직후 기기라 새 폼팩터를 처음부터 설계에 넣을 수 있다 |
| G4 | **기존 데이터와 기능 보존** — 동기화 계층과 웹 패리티를 그대로 유지한다 | 웹(prism.lawdigest.kr)과 같은 데이터를 계속 쓴다 |

## 성공 기준

1. 글래스 카드 가장자리에서 뒤쪽 표지의 굴절이 정지 스크린샷에서도 식별된다.
2. 스크롤하면 표지 벽이 전경보다 느리게(기본 0.35배) 움직여서, 글래스 아래로 지나가는 표지가 계속 바뀐다.
3. 가장 밝은 표지 위에서도 본문 텍스트 대비가 4.5:1 이상이다.
4. 아이폰 듀오 시뮬레이터에서 접기·펼치기를 반복해도 선택한 탭과 기록, 스크롤 위치, 작성 중인 내용이 유지된다.
5. 120Hz 기기에서 홈을 스크롤할 때 Instruments hitch time ratio가 5 ms/s 미만이다.
6. 기존 단위 테스트(WebParity, PayloadFidelity, OfflineBehaviour, TimelineBuilder, RecordsHub)가 모두 통과한다.
7. '투명도 줄이기', '동작 줄이기', 큰 Dynamic Type에서도 모든 기능을 쓸 수 있다.

## 범위 밖

- 백엔드(FastAPI)와 웹(React) 수정. 필요해 보이면 GitHub 이슈로 남긴다.
- 새 기록 카테고리, 소셜 기능, 카메라 연동(`CameraCaptureAccessory` 등).
- iPad 전용 레이아웃. iPad는 regular width 레이아웃을 공유해서 자연스럽게 동작하면 충분하다.
